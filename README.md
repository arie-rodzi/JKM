# Sistem Pemantauan Keberkesanan Psikologi & Kaunseling JKM

Prototype Streamlit premium untuk expected result Kajian Penilaian Keberkesanan Terhadap Perkhidmatan Psikologi dan Kaunseling di JKM.

## Kandungan
- `app.py` — Streamlit dashboard penuh
- `data/JKM_PsyCounsel_Questionnaire_and_Simulation.xlsx` — soalan kuantitatif, panduan temu bual, data simulasi 600 responden dan 90 temu bual
- `requirements.txt` — keperluan Python
- `docs/NOTA_EXPECTED_RESULT.md` — ringkasan output untuk proposal

## Cara run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Nota
Data dalam fail ini ialah simulasi untuk tujuan prototype/expected result sahaja, bukan data sebenar JKM.
