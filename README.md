# JKM Psycho-Counselling Impact Intelligence — SEM + TOR Mapping Version

This version aligns dashboard results with TOR sources S1–S4, constructs K1–K5, questionnaires/instruments, and theories/frameworks.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important
All data in the default dashboard are simulated for tender demonstration only. Replace with actual field data after data collection.

## Main additions
- Overall Satisfaction from S1/CASRS/CSQ-8
- K1–K5 and S1–S4 mapping tab
- Explanation of which result comes from which questionnaire/respondent group
- State and zone comparison
- T1/T2/T3 outcome tracking
- SEM path model and supporting diagnostics
