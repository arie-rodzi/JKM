# Expected Results Note

All results in this demo are simulated for proposal/tender demonstration. SEM coefficients, CR, AVE, HTMT, p-values and R² are illustrative placeholders.

After actual JKM fieldwork, run SEM in AMOS, SmartPLS, or R/lavaan. Replace the simulated SEM table and dashboard values with actual estimates.

Main SEM logic:
Organizational Capacity → Service Quality → Service Mechanism → Client Outcome.

Regression is not the main analysis. Correlation is retained only as a preliminary diagnostic.
